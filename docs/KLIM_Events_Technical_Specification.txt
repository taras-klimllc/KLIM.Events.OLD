# KLIM.Events Service - Comprehensive Technical Specification
Version: v2025-01-22 - Production Ready with Rich Change Events
======================================================================

## EXECUTIVE SUMMARY
====================

The KLIM.Events service is a production-ready .NET 8 Worker Service that implements a comprehensive Change Data Capture (CDC) solution using the Outbox Pattern. It monitors SQL Server databases with Change Tracking enabled, captures entity changes (Issuers, Deals, etc.), and publishes rich change events to RabbitMQ for consumption by downstream systems including Affinity CRM and other external integrations.

**Key Capabilities:**
- ? Rich 2KB+ change events with complete before/after entity snapshots (44+ fields per entity)
- ? Generic entity support with specialized projectors (Issuer, Deal, Instrument, Generic)
- ? Production-ready Outbox Pattern with transactional guarantees
- ? Real-time diagnostics and comprehensive structured logging
- ? Azure AD authentication with SQL Server integration
- ? Adaptive polling with concurrent message processing
- ? Health monitoring with separate liveness/readiness endpoints

**Current Status:** Production ready with critical SQL Change Tracking column mask decoding issues resolved, delivering comprehensive entity change events with complete audit trails.

```
    string[] ChangedFields,                     // Array of changed field names ("*" for inserts)
    Dictionary<string, object?>? PreImage,      // Complete entity state before change (44+ fields)
    Dictionary<string, object?>? PostImage,     // Complete entity state after change (44+ fields)
    Guid? CorrelationId = null                 // Optional correlation ID for tracing
);
```

### IssuerProjector - Complete Implementation

```
/// <summary>
/// Enhanced projector for Issuer entities - captures ALL business columns for comprehensive change events
/// </summary>
public sealed class IssuerProjector : IChangeEventProjector
{
    private static readonly string EventType = typeof(DataChangedV1).AssemblyQualifiedName!;
    
    // Audit fields to exclude from business change filtering  
    private static readonly HashSet<string> AuditFields = new(StringComparer.OrdinalIgnoreCase)
    {
        "ledger_start_transaction_id", "ledger_end_transaction_id",
        "ledger_start_sequence_number", "ledger_end_sequence_number", 
        "ValidFrom", "ValidTo"
    };

    // Comprehensive SQL - all business columns from schema (44+ fields)
    private const string SQL_ISSUER_CURRENT = @"
        SELECT 
            RowGUID, IssuerID, IssuerName, IssuerDesc, IssuerTicker, 
            FigiID, BBGID, IssuerReportingName, BorrowerName, CountryId, 
            VerticalID, MoodysIndustryId, IssuerESGCode, Performing, PublicIssuer, 
            DealLeadID, ParentIssuerID, HSIssuerID, VPMIssuerID, SSIssuerID, 
            WSOIssuerID, PBIIssuerID, ReorgIssuerID, IsBDC, StatusCode, 
            CreatedBy, Created, LastUpdatedBy, LastUpdated, 
            FinalReview, YodaIssuerID, FindoxIssuerID, Restricted, 
            RestrictionStartDate, RestrictionEndDate, LastRestricted, RestrictedBy, 
            RestrictionRemovedBy, RestrictionRemovedOn, RestrictedFlag, Owner, 
            RestrictionReason, SNPIndustryID, GICSIndustryCodeID, GICSSubIndustryId
        FROM dbo.Issuers 
        WHERE IssuerID = @id";

    public bool Supports(string schema, string table) => (schema, table) is ("dbo", "Issuers");

    public async Task<IEnumerable<OutboxInsert>> ProjectAsync(SqlConnection connection, SqlTransaction tx, 
        ChangeTrackingPollingService.TableChangeBatch batch, CancellationToken ct)
    {
        var inserts = new List<OutboxInsert>(batch.Changes.Count);
        
        foreach (var change in batch.Changes)
        {
            var op = change.Operation;
            
            // Filter audit-only changes for Updates
            if (op == "U")
            {
                var businessChangedFields = change.ChangedColumns
                    .Where(field => !AuditFields.Contains(field))
                    .ToArray();
                
                // Skip audit-only updates
                if (businessChangedFields.Length == 0)
                {
                    _logger?.LogDebug("Skipping audit-only update for Issuer {EntityId}", change.Id);
                    continue;
                }
            }

            // Load entity data based on operation
            Guid rowGuid = Guid.Empty;
            string displayName = string.Empty;
            Dictionary<string, object?>? preImage = null;
            Dictionary<string, object?>? postImage = null;

            if (op == "D")
            {
                var hist = await LoadHistoryWindowAsync(connection, tx, change.Id, ct);
                if (hist.Count > 0)
                {
                    rowGuid = hist[0].RowGuid;
                    displayName = GetDisplayName(hist[0].Data);
                    preImage = MessagePublisher.SanitizePayloadData(hist[0].Data);
                }
            }
            else if (op == "I")
            {
                var current = await LoadCurrentAsync(connection, tx, change.Id, ct);
                if (current.HasValue)
                {
                    rowGuid = current.Value.RowGuid;
                    displayName = GetDisplayName(current.Value.Data);
                    postImage = MessagePublisher.SanitizePayloadData(current.Value.Data);
                }
            }
            else if (op == "U")
            {
                var hist = await LoadHistoryWindowAsync(connection, tx, change.Id, ct);
                if (hist.Count > 0)
                {
                    rowGuid = hist[0].RowGuid;
                    displayName = GetDisplayName(hist[0].Data);
                    postImage = MessagePublisher.SanitizePayloadData(hist[0].Data);
                }
                if (hist.Count > 1)
                {
                    preImage = MessagePublisher.SanitizePayloadData(hist[1].Data);
                }
            }

            // Create rich change event
            var evt = new DataChangedV1(
                EntityId: rowGuid,
                EntityType: "Issuer",
                DisplayName: displayName,
                ChangeVersion: change.Version,
                ChangedAt: DateTimeOffset.UtcNow,
                ChangeSource: $"{batch.Schema}.{batch.Table}",
                Operation: op,
                ChangedFields: op switch {
                    "I" => new[] { "*" },
                    "U" => change.ChangedColumns,
                    "D" => new[] { "__Deleted" },
                    _ => Array.Empty<string>()
                },
                PreImage: preImage,
                PostImage: postImage,
                CorrelationId: null
            );

            var payload = JsonSerializer.Serialize(evt, _jsonOptions);
            inserts.Add(new OutboxInsert(
                Id: Guid.NewGuid(),
                Type: EventType,
                Payload: payload,
                OccurredAt: evt.ChangedAt.UtcDateTime,
                MessageKey: $"DataChangedV1|{evt.EntityType}|{evt.EntityId}|{batch.Schema}.{batch.Table}|{change.Version}|{op}",
                SourceEntity: $"{batch.Schema}.{batch.Table}",
                SourceId: evt.EntityId.ToString(),
                ChangeVersion: change.Version
            ));
        }
        
        return inserts;
    }

    // Business-friendly display name generation
    private static string GetDisplayName(Dictionary<string, object?> data)
    {
        var name = data.GetValueOrDefault("IssuerName")?.ToString();
        var ticker = data.GetValueOrDefault("IssuerTicker")?.ToString();
        var reportingName = data.GetValueOrDefault("IssuerReportingName")?.ToString();
        var bbgId = data.GetValueOrDefault("BBGID")?.ToString();
        
        return ticker switch
        {
            not null when name != null => $"{ticker} ({name})",
            not null => $"{ticker} ({reportingName ?? "No Name"})",
            null when bbgId != null => $"{bbgId} ({name ?? reportingName ?? "No Name"})", 
            _ => name ?? reportingName ?? "Unknown Issuer"
        };
    }
}
```

## SQL CHANGE TRACKING IMPLEMENTATION
====================================

### Critical Column Mask Decoding (Fixed)

The system correctly interprets SQL Server Change Tracking column masks as 4-byte integer arrays (column IDs), not bit flags:

```
/// <summary>
/// Decodes SQL Change Tracking column masks correctly as 4-byte integer arrays
/// </summary>
private async Task<string[]> DecodeChangedColumnsAsync(SqlConnection conn, TrackedTable table, byte[]? mask, CancellationToken ct)
{
    if (mask == null || mask.Length == 0) return Array.Empty<string>();
    
    // Cache column metadata per table
    var cacheKey = $"{table.Schema}.{table.Name}";
    if (!_columnCache.TryGetValue(cacheKey, out var cols))
    {
        const string COL_SQL = @"SELECT name FROM sys.columns WHERE object_id = OBJECT_ID(@obj) ORDER BY column_id";
        await using var cmd = new SqlCommand(COL_SQL, conn);
        cmd.Parameters.AddWithValue("@obj", cacheKey);
        await using var reader = await cmd.ExecuteReaderAsync(ct);
        var list = new List<string>();
        while (await reader.ReadAsync(ct)) list.Add(reader.GetString(0));
        cols = list.ToArray();
        _columnCache[cacheKey] = cols;
    }

    // SQL Server Change Tracking stores column IDs as 4-byte integers (little-endian)
    var changed = new List<string>();
    for (int i = 0; i < mask.Length; i += 4)
    {
        if (i + 3 >= mask.Length) break;
        
        int columnId = BitConverter.ToInt32(mask, i);
        
        // Column IDs are 1-based, our array is 0-based
        if (columnId > 0 && columnId <= cols.Length)
        {
            changed.Add(cols[columnId - 1]);
        }
    }
    
    return changed.ToArray();
}
```

### Transactional Guarantees

```
/// <summary>
/// Ensures atomic operation: change detection + outbox insertion in single transaction
/// </summary>
private async Task ProcessTableAsync(SqlConnection conn, TrackedTable table, int batchSize, CancellationToken ct)
{
    // ... change detection logic ...
    
    // Transactional: project -> insert outbox -> advance cursor
    await using var tx = await conn.BeginTransactionAsync(ct);
    try
    {
        var inserts = new List<OutboxInsert>();
        foreach (var projector in _projectors)
        {
            if (!projector.Supports(table.Schema, table.Name)) continue;
            var produced = await projector.ProjectAsync(conn, (SqlTransaction)tx, batchContext, ct);
            inserts.AddRange(produced);
        }

        if (inserts.Count > 0)
        {
            await _outboxWriter.InsertManyAsync(conn, (SqlTransaction)tx, inserts, ct);
        }

        // Advance watermark cursor
        long newCursor = changes[^1].Version;
        await UpdateCursorAsync(conn, (SqlTransaction)tx, full, newCursor, ct);
        await tx.CommitAsync(ct);
    }
    catch (Exception ex)
    {
        await tx.RollbackAsync(CancellationToken.None);
        _log.LogError(ex, "Projection failed for {Table}; rolled back.", full);
        throw;
    }
}
```

```
        cfg.Send<DataChangedV1>(s => s.UseRoutingKeyFormatter(_ => "data.changed.v1"));
```

### Message Publishing with Payload Monitoring

```
/// <summary>
/// Publishes messages to RabbitMQ with payload size monitoring and optimization
/// </summary>
public async Task<PublishResult> PublishAsync(OutboxMessage message, CancellationToken cancellationToken)
{
    // Payload size monitoring with safety limits
    var payloadSizeBytes = System.Text.Encoding.UTF8.GetByteCount(message.Payload);
    
    // Safety checks
    if (payloadSizeBytes > MAX_PAYLOAD_SIZE_BYTES) // 2MB limit
    {
        return PublishResult.Failed($"Payload too large: {payloadSizeBytes / 1024}KB");
    }

    // Warning for large payloads
    if (payloadSizeBytes > LARGE_PAYLOAD_THRESHOLD) // 500KB threshold
    {
        _logger.LogWarning("Large payload detected: {PayloadSize}KB", payloadSizeBytes / 1024);
    }

    // Deserialize and publish
    var messageType = Type.GetType(message.Type);
    var messageObj = JsonSerializer.Deserialize(message.Payload, messageType, _jsonOptions);
    
    await _bus.Publish(messageObj, ctx =>
    {
        ctx.MessageId = message.Id;
        ctx.Headers.Set("OccurredAt", message.OccurredAt.ToString("O"));
        ctx.Headers.Set("PayloadSizeKB", (payloadSizeBytes / 1024).ToString());
    }, cancellationToken);

    return PublishResult.Success("klim.change.events", "data.changed.v1", ExtractChangeDetails(messageObj));
}
```

```
/// <summary>
/// Real-time diagnostics service that reports system health every 5 minutes
/// </summary>
public sealed class OutboxDiagnosticService : BackgroundService
{
    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        using var timer = new PeriodicTimer(TimeSpan.FromMinutes(5));
        
        while (!stoppingToken.IsCancellationRequested)
        {
            try
            {
                var metrics = await GatherMetricsAsync(stoppingToken);
                
                _logger.LogInformation("System Health Report: " +
                    "Pending={PendingMessages}, " +
                    "Dispatched(1h)={DispatchedLastHour}, " +
                    "AvgDispatchTime={AvgDispatchTimeMs}ms, " +
                    "ErrorRate={ErrorRate}%, " +
                    "OldestPending={OldestPendingMinutes}min",
                    metrics.PendingMessages,
                    metrics.DispatchedLastHour,
                    metrics.AvgDispatchTimeMs,
                    metrics.ErrorRate,
                    metrics.OldestPendingMinutes);
            }
            catch (Exception ex)
            {
                _logger.LogWarning(ex, "Failed to gather diagnostic metrics");
            }
            
            try { await timer.WaitForNextTickAsync(stoppingToken); }
            catch (OperationCanceledException) when (stoppingToken.IsCancellationRequested) { break; }
        }
    }
}
```

## AFFINITY CRM INTEGRATION GUIDANCE

### Consumer Implementation Pattern

For systems consuming KLIM.Events messages (like Affinity CRM), implement the following pattern:

```
/// <summary>
/// Sample consumer for Affinity CRM integration
/// </summary>
public class AffinityDataChangedConsumer : IConsumer<DataChangedV1>
{
    private readonly IAffinityApiClient _affinityClient;
    private readonly ILogger<AffinityDataChangedConsumer> _logger;

    public async Task Consume(ConsumeContext<DataChangedV1> context)
    {
        var message = context.Message;
        
        using var scope = _logger.BeginScope(new Dictionary<string, object>
        {
            ["EntityType"] = message.EntityType,
            ["EntityId"] = message.EntityId,
            ["Operation"] = message.Operation,
            ["ChangeVersion"] = message.ChangeVersion,
            ["CorrelationId"] = context.CorrelationId
        });

        _logger.LogInformation("Processing {EntityType} change: {Operation} for {DisplayName}",
            message.EntityType, message.Operation, message.DisplayName);

        try
        {
            switch (message.EntityType)
            {
                case "Issuer":
                    await ProcessIssuerChangeAsync(message);
                    break;
                case "Deal":
                    await ProcessDealChangeAsync(message);
                    break;
                default:
                    _logger.LogWarning("Unsupported entity type: {EntityType}", message.EntityType);
                    return;
            }

            _logger.LogInformation("Successfully processed {EntityType} change for {DisplayName}",
                message.EntityType, message.DisplayName);
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Failed to process {EntityType} change for {DisplayName}",
                message.EntityType, message.DisplayName);
            throw; // Let MassTransit handle retries
        }
    }

    private async Task ProcessIssuerChangeAsync(DataChangedV1 message)
    {
        switch (message.Operation)
        {
            case "I": // Insert
                var createRequest = MapToAffinityCreateRequest(message.PostImage);
                await _affinityClient.CreateIssuerAsync(createRequest);
                break;

            case "U": // Update
                var updateRequest = MapToAffinityUpdateRequest(message.PreImage, message.PostImage, message.ChangedFields);
                await _affinityClient.UpdateIssuerAsync(message.EntityId, updateRequest);
                break;

            case "D": // Delete
                await _affinityClient.DeleteIssuerAsync(message.EntityId);
                break;
        }
    }

    private AffinityIssuerCreateRequest MapToAffinityCreateRequest(Dictionary<string, object?>? postImage)
    {
        if (postImage == null) throw new ArgumentException("PostImage required for create operation");

        return new AffinityIssuerCreateRequest
        {
            Name = postImage.GetValueOrDefault("IssuerName")?.ToString(),
            Description = postImage.GetValueOrDefault("IssuerDesc")?.ToString(),
            Ticker = postImage.GetValueOrDefault("IssuerTicker")?.ToString(),
            FigiId = postImage.GetValueOrDefault("FigiID")?.ToString(),
            BloombergId = postImage.GetValueOrDefault("BBGID")?.ToString(),
            // ... map other relevant fields
        };
    }

    private AffinityIssuerUpdateRequest MapToAffinityUpdateRequest(Dictionary<string, object?>? preImage, 
        Dictionary<string, object?>? postImage, string[] changedFields)
    {
        if (postImage == null) throw new ArgumentException("PostImage required for update operation");

        var updateRequest = new AffinityIssuerUpdateRequest();

        // Only update changed fields for efficiency
        foreach (var field in changedFields)
        {
            switch (field.ToLowerInvariant())
            {
                case "issuername":
                    updateRequest.Name = postImage.GetValueOrDefault("IssuerName")?.ToString();
                    break;
                case "issuerdesc":
                    updateRequest.Description = postImage.GetValueOrDefault("IssuerDesc")?.ToString();
                    break;
                case "issuerticker":
                    updateRequest.Ticker = postImage.GetValueOrDefault("IssuerTicker")?.ToString();
                    break;
                case "figiid":
                    updateRequest.FigiId = postImage.GetValueOrDefault("FigiID")?.ToString();
                    break;
                case "bbgid":
                    updateRequest.BloombergId = postImage.GetValueOrDefault("BBGID")?.ToString();
                    break;
                // ... handle other fields as needed
            }
        }

        return updateRequest;
    }
```

```
// Automatic payload sanitization for large text fields
public static Dictionary<string, object?> SanitizePayloadData(Dictionary<string, object?> data)
{
    var sanitized = new Dictionary<string, object?>(data.Count);
    
    foreach (var kvp in data)
    {
        var value = kvp.Value;
        if (value is string str && str.Length > MAX_TEXT_FIELD_LENGTH) // 10KB limit
        {
            // Truncate very large text fields with metadata
            sanitized[kvp.Key] = str[..(MAX_TEXT_FIELD_LENGTH - 100)] + 
                $"... [TRUNCATED - original length: {str.Length} chars]";
            sanitized[$"{kvp.Key}_Truncated"] = true;
            sanitized[$"{kvp.Key}_OriginalLength"] = str.Length;
        }
        else
        {
            sanitized[kvp.Key] = value;
        }
    }
    
    return sanitized;
}
```

## TROUBLESHOOTING GUIDE
=======================

### Common Issues & Solutions

1. **Empty Payloads (PreImage/PostImage null)**
   - **Cause:** SQL Change Tracking column mask decoding issue
   - **Solution:** Verify DecodeChangedColumnsAsync uses 4-byte integer interpretation
   - **Check:** `SELECT SYS_CHANGE_COLUMNS` from CHANGETABLE should show non-zero byte arrays

2. **SQL Connection Failures**
   - **Cause:** Azure AD token expiration or invalid credentials
   - **Solution:** Ensure DefaultAzureCredential chain is properly configured
   - **Check:** Connection string sanitization removes User ID/Password for Azure AD

3. **Message Publishing Failures**
   - **Cause:** RabbitMQ connectivity or exchange configuration
   - **Solution:** Verify topic exchange "klim.change.events" exists
   - **Check:** MassTransit configuration and routing key "data.changed.v1"

4. **Performance Issues**
   - **Cause:** Large payload sizes or inefficient SQL queries
   - **Solution:** Enable payload sanitization and optimize projector queries
   - **Check:** Monitor payload size warnings in logs
